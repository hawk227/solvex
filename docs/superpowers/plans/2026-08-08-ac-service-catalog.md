# AC Service Catalog Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 3 placeholder demo AC services with the real 16-entry Solvex-branded AC catalog from the reference document, and add a new `service_costing` table (+ CMS tab) to capture the internal delivery-cost data (material, tools, resource count/cost, service time, travel cost, internal cost, technician SOP) the current schema has no column for.

**Architecture:** One additive migration (`service_costing`, 1:1 with `services`, no changes to `services`/`service_prices`). One idempotent seed SQL file generated by a one-off Node script (mirrors the project's existing `geography-seed.sql` convention). One new CMS tab on the service detail page, following the exact pattern of the existing Content tab (client component + one server action).

**Tech Stack:** Drizzle ORM, Cloudflare D1, Next.js Server Actions, Zod.

## Global Constraints

- No changes to `services` or `service_prices` beyond normal row inserts/updates through existing, already-tested code paths (`createService`, `updateServiceBasics`, `updateServiceContent`). `service_costing` is a new, separate table.
- `internalCost` and `sopMd` are never read by any customer-facing query. `solvex-webapp/src/lib/catalog.ts`'s `getServiceBySlug`/`getServices`/`getServiceVariables`/`getServicePrices` are not modified by this plan — confirm after Task 1 that none of them accidentally start selecting from `service_costing`.
- The 3 existing demo AC services (slugs `ac-cleaning`, `ac-health-checkup`, `ac-gas-refill`) are deactivated (`active = 0`), never deleted.
- Every "Sheba.xyz" in the source reference text is written as "Solvex" in the seed data — authored correctly, never substituted after the fact.
- No production database write without a separate explicit confirmation from the user, after local verification — same as every other production data change made this session.
- Every new/modified exported function in a file starting with `'use server'` must call `requireManage('catalog')` and `audit(...)`, per the existing repo-wide guard test `solvex-cms/src/lib/action-guards.test.ts`.

- [ ] **Step 1: Add the table to the schema**

In `packages/db/src/schema/catalog.ts`, add this after the existing `servicePricesRelations` block (end of file):

```ts
/**
 * Internal delivery-cost data for a service: material, tools, technician
 * count, resource/travel cost, service time, and a technician SOP. None of
 * this is customer-facing — `services`/`service_prices` (what the booking
 * flow and public site actually read) are untouched by this table.
 */
export const serviceCosting = sqliteTable('service_costing', {
  serviceId: integer('service_id')
    .primaryKey()
    .references(() => services.id, { onDelete: 'cascade' }),
  material: text('material'),
  tools: text('tools'),
  // Text, not integer: some source values are ranges ("2/3"), not counts.
  resourceCount: text('resource_count'),
  resourceCost: integer('resource_cost'),
  // The source's raw string ("1.30 H", "6 to 24 H", "30 min"), kept
  // verbatim since some are ranges that don't reduce to one number.
  // services.durationMin is filled separately where a clean value exists.
  serviceTimeLabel: text('service_time_label'),
  travelCost: integer('travel_cost'),
  // What it costs Solvex to deliver — distinct from services/service_prices,
  // which is what the customer pays. CMS-only; never read by the public site.
  internalCost: integer('internal_cost'),
  // Technician-facing step-by-step instructions. Null for most services.
  sopMd: text('sop_md'),
});

export const serviceCostingRelations = relations(serviceCosting, ({ one }) => ({
  service: one(services, { fields: [serviceCosting.serviceId], references: [services.id] }),
}));
```

```js
const DEACTIVATE_SLUGS = ['ac-cleaning', 'ac-health-checkup', 'ac-gas-refill'];

function esc(s) {
  if (s === null || s === undefined) return 'NULL';
  return `'${String(s).replace(/'/g, "''")}'`;
}

function escList(items) {
  if (!items || items.length === 0) return 'NULL';
  return esc(JSON.stringify(items));
}

function escFaqs(pairs) {
  if (!pairs || pairs.length === 0) return 'NULL';
  const objs = pairs.map(([q, a]) => ({ q, a }));
  return esc(JSON.stringify(objs));
}

lines.push('-- reference AC service/price document. Idempotent: upserts by slug, so');
lines.push('-- re-running after a content edit updates existing rows rather than');
lines.push('-- duplicating them.');
lines.push('');

lines.push('-- The old demo AC services are superseded by the real catalog below.');
lines.push('-- Deactivated, not deleted (orders/tickets may still reference them).');
for (const slug of DEACTIVATE_SLUGS) {
  lines.push(`UPDATE services SET active = 0 WHERE slug = ${esc(slug)};`);
}
lines.push('');

  lines.push(`-- ${svc.name}`);

      `AND NOT EXISTS (SELECT 1 FROM services WHERE slug = ${esc(svc.slug)});`,
  );
  lines.push(
    `UPDATE services SET name = ${esc(svc.name)}, short_desc = ${esc(svc.shortDesc)}, duration_min = ${durationSql}, ` +
      `sort = ${sort}, active = 1, about_md = ${esc(svc.about)}, included_json = ${escList(svc.included)}, ` +
      `not_included_json = ${escList(svc.excluded)}, faqs_json = ${escFaqs(svc.faqs)} WHERE slug = ${esc(svc.slug)};`,
  );

  if (svc.price !== null && svc.price !== undefined) {
    lines.push(
      `INSERT INTO service_prices (service_id, combo_key, price) ` +
        `SELECT id, '', ${svc.price} FROM services WHERE slug = ${esc(svc.slug)} ` +
        `AND NOT EXISTS (SELECT 1 FROM service_prices WHERE service_id = (SELECT id FROM services WHERE slug = ${esc(svc.slug)}) AND combo_key = '');`,
    );
    lines.push(
      `UPDATE service_prices SET price = ${svc.price} ` +
        `WHERE service_id = (SELECT id FROM services WHERE slug = ${esc(svc.slug)}) AND combo_key = '';`,
    );
  }

  lines.push(
    `INSERT INTO service_costing (service_id, material, tools, resource_count, resource_cost, service_time_label, travel_cost, internal_cost, sop_md) ` +

      `${esc(svc.serviceTimeLabel)}, ${svc.travelCost ?? 'NULL'}, ${svc.cost ?? 'NULL'}, ${esc(svc.sopMd ?? null)} ` +
      `FROM services WHERE slug = ${esc(svc.slug)} ` +
      `AND NOT EXISTS (SELECT 1 FROM service_costing WHERE service_id = (SELECT id FROM services WHERE slug = ${esc(svc.slug)}));`,
  );
  lines.push(
    `UPDATE service_costing SET material = ${esc(svc.material)}, tools = ${esc(svc.tools)}, ` +

      `internal_cost = ${svc.cost ?? 'NULL'}, sop_md = ${esc(svc.sopMd ?? null)} ` +
      `WHERE service_id = (SELECT id FROM services WHERE slug = ${esc(svc.slug)});`,
  );

  lines.push('');
```

```ts
export async function updateServiceCosting(id: number, formData: FormData): Promise<ActionResult> {
  await requireManage('catalog');

  const parsed = CostingInput.safeParse({
    material: formData.get('material'),
    tools: formData.get('tools'),
    resourceCount: formData.get('resourceCount'),
    resourceCost: formData.get('resourceCost') || undefined,
    serviceTimeLabel: formData.get('serviceTimeLabel'),
    travelCost: formData.get('travelCost') || undefined,
    internalCost: formData.get('internalCost') || undefined,
    sopMd: formData.get('sopMd'),
  });
  if (!parsed.success) {
    return { ok: false, error: parsed.error.issues[0]?.message ?? 'Invalid input.' };
  }

  const { material, tools, resourceCount, resourceCost, serviceTimeLabel, travelCost, internalCost, sopMd } =
    parsed.data;

  await db()
    .insert(schema.serviceCosting)
    .values({
      serviceId: id,
      material: material || null,
      tools: tools || null,
      resourceCount: resourceCount || null,
      resourceCost: resourceCost ?? null,
      serviceTimeLabel: serviceTimeLabel || null,
      travelCost: travelCost ?? null,
      internalCost: internalCost ?? null,
      sopMd: sopMd || null,
    })
    .onConflictDoUpdate({
      target: schema.serviceCosting.serviceId,
      set: {
        material: material || null,
        tools: tools || null,
        resourceCount: resourceCount || null,
        resourceCost: resourceCost ?? null,
        serviceTimeLabel: serviceTimeLabel || null,
        travelCost: travelCost ?? null,
        internalCost: internalCost ?? null,
        sopMd: sopMd || null,
      },
    });

  // Not the values themselves — internalCost in particular is sensitive
  // margin data, and the log only needs to show that it changed.
  await audit({
    action: 'catalog.service.costing.update',
    module: 'catalog',
    targetType: 'service',
    targetId: id,
  });

  revalidatePath(`/admin/services/${id}`);
  return { ok: true };
}
```

```tsx
import { Field, Input, Textarea } from '@/components/ui/input';
import { updateServiceCosting } from '../actions';

export function CostingEditor({
  serviceId,
  material,
  tools,
  resourceCount,
  resourceCost,
  serviceTimeLabel,
  travelCost,
  internalCost,
  sopMd,

  serviceId: number;

  resourceCost: string;
  serviceTimeLabel: string;

  internalCost: string;

        <Field label="Tools" htmlFor="tools" hint="e.g. Regular Tool, Gas Meter & Ampere Meter">
          <Input id="tools" name="tools" defaultValue={tools} />
        </Field>
        <Field label="Resource count" htmlFor="resourceCount" hint="Technicians needed, e.g. 2 or 2/3">
          <Input id="resourceCount" name="resourceCount" defaultValue={resourceCount} />
        </Field>
        <Field label="Resource cost (৳)" htmlFor="resourceCost">
          <Input id="resourceCost" name="resourceCost" type="number" min={0} defaultValue={resourceCost} />
        </Field>
        <Field label="Service time" htmlFor="serviceTimeLabel" hint="e.g. 1.30 H or 6 to 24 H">
          <Input id="serviceTimeLabel" name="serviceTimeLabel" defaultValue={serviceTimeLabel} />
        </Field>
        <Field label="Travel cost (৳)" htmlFor="travelCost">
          <Input id="travelCost" name="travelCost" type="number" min={0} defaultValue={travelCost} />
        </Field>
        <Field label="Internal cost (৳)" htmlFor="internalCost" hint="What this costs Solvex to deliver — never shown to customers.">
          <Input id="internalCost" name="internalCost" type="number" min={0} defaultValue={internalCost} />
        </Field>
      </div>

      <Field label="Technician SOP" htmlFor="sopMd" hint="Step-by-step completion checklist, one step per line. Optional.">
        <Textarea id="sopMd" name="sopMd" defaultValue={sopMd} className="min-h-40" />

        <p role="alert" className="text-[13px] text-[var(--color-danger)]">

          Costing saved.
        </p>
      )}

      <div>
        <Button type="submit" disabled={pending}>
          {pending ? 'Saving…' : 'Save costing'}
        </Button>
      </div>
    </form>
```
